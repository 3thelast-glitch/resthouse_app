# مراجعة إصلاح الواجهة العربية المتجاوبة

تاريخ المراجعة: 2026-09-16. طلب المراجعة: [PR #23](https://github.com/3thelast-glitch/resthouse_app/pull/23). التغييرات على فرع إصلاح مستقل؛ لم تُدمج ولم يُنشر إصدار.

## النطاق والتقنية

المشروع Flutter/Dart فعليًا. يستخدم سير البناء Flutter 3.35.7؛ Dart المشغّل 3.9.2 وقيده في `pubspec.yaml` هو `^3.9.0`. الحزم ذات الصلة: `table_calendar 3.2.0` و`fl_chart 1.2.0` و`intl 0.20.2`. نقطة الدخول `lib/main.dart`، والثيم `lib/theme/app_theme.dart`، والتنقل `lib/pages/main_shell.dart`. إدارة حالة الواجهة محلية بـ`StatefulWidget` والتخزين SQLite عبر `DatabaseHelper`.

اللغة المهيأة حاليًا عربية سعودية، والخط المضمّن IBM Plex Sans Arabic؛ لم تُضف حزمة خطوط شبكية أو منظومة لغات جديدة. لم تتغير قاعدة البيانات أو الخدمات أو حسابات الحجز والتحصيل أو إعدادات توقيع Android أو التبعيات.

الصور الأصلية الثلاث لم تكن مرفقة في السياق المتاح. استند التشخيص إلى وصف المستخدم والكود، ثم إلى تشغيل اختبارات الواجهة. لا توجد مقارنة صور قبل/بعد متماثلة، ولم يُستنتج عرض الهاتف من أبعاد صورة. لم أزعم إعادة إنتاج مقدار 51 بكسل نفسه؛ أُزيلت القيود التي تثبت وجود سبب للتجاوز.

## قواعد الاستجابة الفعلية

تتبع القرارات [منهج Flutter للتخطيط المتكيف](https://docs.flutter.dev/ui/adaptive-responsive/general): `LayoutBuilder` للمساحة المحلية و`MediaQuery` لتكبير النص وحواف النظام. القياسات التالية وحدات منطقية.

- حد عرض المحتوى 1440، وهوامش الهاتف 16، والفاصل المعتاد 12. لا نسب `childAspectRatio` مفروضة على البطاقات النصية.
- عدد أعمدة المجموعة = الجزء الصحيح من `(العرض المتاح + 12) / (الحد الأدنى للعنصر × معامل النص + 12)`، مع التقيد بعدد الأعمدة الأقصى. لا يُنقص المعامل عن 1 عند حساب الحد الأدنى. المتاح دون 328 يُبقي عمودًا واحدًا.
- بطاقات الإحصاءات: حد أدنى 210، وحد أقصى 3 أعمدة. عند النص الافتراضي تبدأ بطاقة ثانية عند 432 من المساحة الداخلية، وثالثة عند 654. في شاشة الهاتف ذات الهوامش 16 يقابل ذلك عرضي 464 و686؛ وجود شريط جانبي يغير عرض المحتوى المتاح.
- أزرار لوحة التحكم: 220 للعنصر؛ أزرار الحجز 230؛ الفلاتر 200؛ تفاصيل المبالغ 180. هذه الحدود تزيد مع تكبير النص.
- تقرير لوحة التحكم والأنشطة: 480 لكل قسم؛ رسوم المالية: 460 لكل قسم. لا يظهر قسمان إلا بعد احتساب الفاصل.
- الحجوزات: لوحتان عند عرض الحاوية `1024 × معامل النص` أو أكثر. مع النص الافتراضي، عرض كل لوحة الداخلي يقارب 480 بعد الهوامش. على عرض أصغر يعود التقويم والقائمة إلى ترتيب رأسي. التقويم قابل للطي والتاريخ المختار ظاهر.
- الشريط الجانبي يظهر عند عرض نافذة 800. بقاء الحالة اختُبر حول 799/800/801. تحسب الصفحات المساحة المتبقية بعده، لا عرض النافذة الكامل.
- التنقل السفلي محجوز في `Scaffold.bottomNavigationBar`؛ عند تكبير النص فوق 1.25 ينتقل إلى توزيع مرن ذي صفين في الهاتف. الحواف الآمنة لا تُحتسب مرتين.
- العملة مفصولة عن المبلغ في `Wrap`، والمقطع الرقمي LTR فقط. لا حذف للأرقام أو وحدات العملة ولا اختصار للمبالغ. القيمة المالية الطويلة جدًا تنتقل من خط العنوان إلى حجم أساسي 16 مع الاحتفاظ بتكبير النظام، بعد إعادة توزيع الأعمدة.
- التقويم يحتفظ بالهجري أعلى الخلية والميلادي أسفلها، وبكامل أعمدة الأسبوع. يزداد ارتفاع الصف مع النص. أيام الأسبوع تستخدم اختصارات عند الضيق مع أسماء كاملة في التلميحات.
- الرسم يحافظ على جميع الأعمدة والقيم وترتيبها؛ تقل كثافة تسميات المحور فقط. المدى يشمل الصفر ويتعامل مع القيم الصفرية والمتساوية والسالبة.

## منهج الاختبار

كل اختبار يستخدم قاعدة SQLite مؤقتة مستقلة، ولا يصل إلى بيانات المستخدم. الغلاف يتضمن الثيم والتوطين العربي وRTL، مع تحميل الخط العربي وخط Material Icons الفعليين. كثافة البكسل في الاختبار 1 لتحقيق الأبعاد المنطقية المحددة، وتُعاد إعدادات العرض والتكبير بعد الاختبارات.

التحقق يتجاوز غياب الاستثناء: يفحص حدود النصوص أفقيًا، وعدم تجاوز `maxLines`، وعدم تقسيم الكلمات العربية والأرقام المالية والتواريخ بين أسطر، والتمرير حتى النهاية، وقابلية النقر على الإجراءات الأساسية. لا تُخفى أخطاء Flutter ولا تُعدل معالجاتها. الانتظار للبيانات محدود زمنيًا.

## الصور وحدود التحقق

هذه صور فعلية للويدجت من محرك Flutter أثناء الاختبار على GitHub Actions، وليست صورًا مولّدة أو تصاميم تخيلية. صورة النموذج تستخدم `viewInsets` لمحاكاة المساحة المحجوزة للوحة المفاتيح؛ لا تعرض لوحة مفاتيح Android حقيقية.

- [بناء Android](https://github.com/3thelast-glitch/resthouse_app/actions/runs/35080847063): نجح `flutter build apk --debug --no-pub` وأنتج `build/app/outputs/flutter-apk/app-debug.apk`.
- [تنزيل حزمة APK التجريبية](https://github.com/3thelast-glitch/resthouse_app/actions/runs/35080847063/artifacts/10440212822). حزمة GitHub هذه متاحة حتى 2026-09-30 وفق مدة الاحتفاظ. قد يلزم تسجيل الدخول إلى GitHub لتنزيلها.
- الصور والبناء المذكوران من الالتزام `a86aab2e1b819060a684f6cc5054cb5463e3219a`؛ الحفظ اللاحق يتضمن التنسيق والتوثيق والصور وبوابة التحقق فقط. روابط أحدث تحقق للمصدر المحفوظ موجودة في طلب المراجعة.
- روجعت الصور التسع بصريًا: الأيقونات والخط العربي محملان، الكلمات والمبالغ مقروءة، وتظهر نهاية قائمة الأنشطة فوق التنقل. بعض الصور التُقطت بعد التمرير، لذا خروج بداية البطاقة أو جزء من التقويم أعلى الصورة لا يعني حذف المحتوى.

لم تبقَ استثناءات تخطيط في الحالات المختبرة. تظل حدود التحقق هي غياب تجربة جهاز Android الفعلي والمحاكي وTalkBack ولوحة مفاتيح حقيقية. لعدم توفر الصور الأصلية، لا يمكن إثبات تطابق الحالة الأصلية ذات التجاوز 51 بكسل حرفيًا.
