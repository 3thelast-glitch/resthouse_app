## نطاق المشروع

يركز التطبيق على إدارة تشغيل استراحة واحدة من جهاز محلي. ويعني ذلك أن البيانات تبقى في قاعدة SQLite على الجهاز الذي يشغّل التطبيق، وأن نقلها يتم بالنسخة الاحتياطية JSON. لا تتوافر حاليًا مزامنة سحابية، أو صلاحيات مستخدمين متعددة، أو واجهة ويب مدعومة للتشغيل اليومي.

## البدء ببيانات فارغة

> **الإدخال يدوي فقط:** لا تضيف النسخة التشغيلية مستأجرين أو حجوزات أو مصروفات تجريبية. تبدأ القوائم والتقارير فارغة، ثم تظهر بياناتك وتقاريرك تلقائيًا بعد حفظ أول سجل فعلي.

إذا كانت نسخة قديمة من التطبيق تحتوي على سجلات سابقة، فافتح **الإعدادات → مسح جميع البيانات المحلية** ثم أكّد الإجراء. ينشئ التطبيق نسخة JSON للاستعادة قبل المسح، وبعده تصبح قوائم المستأجرين والحجوزات والتقارير المالية فارغة وجاهزة للإدخال اليدوي. لا تستخدم هذا الإجراء إذا كنت تريد الاحتفاظ بالسجلات الحالية؛ صدّر نسخة احتياطية أو استعدها لاحقًا عند الحاجة.

## الميزات الحالية

| المجال | ما يدعمه التطبيق حاليًا |
|---|---|
| الحجوزات | إنشاء وتعديل وحذف الحجوزات، ومنع تداخل الفترات، وحالات الحجز والتأمين، وعرض تقويم هجري وميلادي. |
| المستأجرون | حفظ بيانات المستأجر وسجل الحجوزات وعدد مرات الاستئجار والملاحظات والتقييم. |
| الدفعات | تسجيل دفعات مرتبطة بالحجز، احتساب المقبوض والمتبقي، ومنع تجاوز مجموع الدفعات لقيمة الحجز. |
| تصحيح الدفعات | إلغاء الدفعة المؤكدة بسبب إلزامي بدل حذف أثرها؛ ولا تدخل الدفعة الملغاة في المقبوض أو الرصيد المتبقي. |
| المالية | عرض الإيرادات والمصروفات وصافي النقد والأرصدة المستحقة والتأمينات المعلقة وفق منطق مالي موحد. |
| التدقيق | تسجيل أحداث إنشاء/تعديل/حذف الحجوزات والدفعات وتغيير حالة التأمين في سجل تدقيق داخلي. |
| المهام التشغيلية | توفير محرك يحسب الأرصدة المستحقة، والتأمينات غير المسوّاة، والحجوزات التي تبدأ اليوم؛ وتهيئة هذه النتائج للربط لاحقًا بمركز تنبيهات مرئي. |
| النسخ الاحتياطي | تصدير واستعادة بيانات المستأجرين والحجوزات والمصروفات والدفعات بصيغة JSON بعد التحقق من سلامة العلاقات. |
| البداية وإدخال البيانات | يبدأ التطبيق بقوائم فارغة ولا يضيف أي مستأجرين أو حجوزات أو مصروفات تجريبية؛ يدخل المستخدم جميع بيانات التشغيل يدويًا. |
| إفراغ البيانات | يمكن إنشاء نسخة استعادة JSON ثم مسح جميع البيانات المحلية المؤكدة للبدء بقوائم وتقارير فارغة. |

## البنية التقنية والبيانات

يعتمد المشروع على Flutter وDart، مع SQLite للبيانات المحلية. يستخدم Android وiOS حزمة `sqflite`، فيما تعتمد منصات سطح المكتب على `sqflite_common_ffi`. ويظهر تعريف الحزم وإصداراتها المعتمدة في [`pubspec.yaml`](pubspec.yaml).

| المكوّن | المسؤولية |
|---|---|
| [`lib/database_helper.dart`](lib/database_helper.dart) | تهيئة SQLite، ترحيلات المخطط، عمليات البيانات، الدفعات، سجل التدقيق والنسخ الاحتياطي. الإصدار الحالي لمخطط القاعدة هو **8**. |
| [`lib/services/financial_summary_service.dart`](lib/services/financial_summary_service.dart) | حساب الإيراد والمقبوض والرصيد والمصروفات وصافي النقد وفق قواعد موحدة. |
| [`lib/services/operations_task_service.dart`](lib/services/operations_task_service.dart) | اشتقاق المهام التشغيلية من الحجوزات والدفعات. |
| [`lib/pages/`](lib/pages) | واجهات لوحة التحكم والحجوزات والمالية والإعدادات وبنية التنقل الرئيسية. |
| [`test/`](test) | اختبارات قاعدة البيانات والخدمات المالية ومحرك المهام والواجهات. |
| [`.github/workflows/ci.yml`](.github/workflows/ci.yml) | تشغيل `flutter pub get` ثم `flutter analyze` و`flutter test` آليًا على `main` وطلبات الدمج. |

تتكون قاعدة البيانات من الجداول التالية: `renters` للمستأجرين، و`bookings` للحجوزات، و`expenses` للمصروفات، و`payments` للدفعات، و`audit_events` لأحداث التدقيق. ترتبط الدفعات بالحجوزات وتحتفظ بحالة الدفعة وتفاصيل الإلغاء عند الحاجة.

## التثبيت والتشغيل

### المتطلبات

يلزم تثبيت Flutter stable الذي يتضمن Dart متوافقًا مع القيد `^3.9.0` في [`pubspec.yaml`](pubspec.yaml). وتحتاج منصات الأجهزة إلى أدواتها الأصلية، مثل Android Studio وAndroid SDK لأندرويد، أو Xcode لبيئة iOS وmacOS. على Windows، يلزم أيضًا إعداد أدوات بناء سطح المكتب الخاصة بـ Flutter.

### استنساخ المشروع وتجهيز الحزم

```bash
git clone https://github.com/3thelast-glitch/resthouse_app.git
cd resthouse_app
flutter pub get
flutter devices
```

يعرض الأمر الأخير الأجهزة والمحاكيات المتاحة ومعرّفاتها. بعد ذلك شغّل التطبيق بالمعرّف المناسب:

```bash
flutter run -d <device-id>
```

### أمثلة للبناء

```bash
# Android APK
flutter build apk --release

# Windows
flutter build windows --release

# Linux
flutter build linux --release

# macOS
flutter build macos --release

# iOS — على macOS فقط، وبعد إعداد التوقيع في Xcode
flutter build ipa --release
```

## النسخ الاحتياطي

من شاشة الإعدادات يمكن إنشاء نسخة JSON تشمل المستأجرين والحجوزات والمصروفات والدفعات. عند الاستعادة، يتحقق التطبيق من صيغة الملف وعلاقاته قبل تنفيذ العملية داخل معاملة واحدة. كما ينشئ التطبيق نسخة JSON تلقائية قبل مسح جميع البيانات المحلية أو استيراد نسخة بديلة. احتفظ بالنسخ الاحتياطية في موقع آمن، واختبر الاستعادة على نسخة من البيانات قبل استبدال بيانات تشغيلية مهمة.

> لا تشمل النسخة الاحتياطية الحالية سجل `audit_events`؛ فهو سجل تشخيصي محلي منفصل عن بيانات التشغيل القابلة للاستعادة.
